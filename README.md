# Pictica（ピクチカ）

複数の写真を 1 枚の 2L 判（127 × 178 mm）に並べて、印刷用の画像を作るツールです。
HTML ファイル 1 つで動きます。写真はブラウザの中だけで処理し、外部には送信しません。

## 使い方

1. `index.html` をブラウザで開く（ダブルクリックで OK。サーバーは不要です）
2. タイトル画面で「最初から」を選び、写真をまとめて追加する
   - 編集の内容は自動で保存され、次に開いたとき「前回の続きから」で再開できます（同じ端末・同じブラウザのみ）
3. 枠をタップして選び、下に並んだ写真をタップ（またはドラッグ）してはめる
   - 「自動で並べる」で、空いている枠に順番に入れることもできます
4. 枠の中で写真を調整する
   - ドラッグ: 位置を動かす
   - 2 本指ピンチ / マウスホイール: 拡大・縮小
   - 2 本指でひねる: 回転（0° / 90° / 180° / 270° の前後で引っかかって止まる。回し続けると抜ける）
   - PC: Shift + ホイール、またはツールバーの角度スライダーでも回転
   - ダブルタップ: 位置と拡大をリセット
   - ツールバー: 90° 回転・左右反転・リセット・入れ替え・外す
5. 上の「＋ページ」で、今のページと同じ設定（用紙・向き・分割・枠）のページを追加できます
   - ページごとに設定を変えられます。ゴミ箱アイコンで今のページを削除
   - 「自動で並べる」は、どのページにもまだ使っていない写真から入れていきます
6. 間違えたら上の「戻る」（Ctrl / ⌘ + Z）でひとつ前に戻せます（「やり直す」は Ctrl / ⌘ + Shift + Z）
7. 「書き出す」で全ページを JPEG / PNG にする（300 dpi または 350 dpi。解像度情報も埋め込みます）。ページごとに保存するか、ZIP でまとめて保存できます

## 設定

| 項目 | 内容 |
| --- | --- |
| 用紙 | L判 / KG / 2L判 / A4、縦・横 |
| 分割 | 1〜12 枚のプリセット 18 種類と、行 × 列（最大 6 × 6）のカスタム |
| 枠 | 枠の有無、外側の幅、写真の間隔、角の丸み、枠の色 |
| その他 | カット用ガイド線、低解像度の警告 |

画面の大きさに合わせてレイアウトが変わります（スマホ縦・横、タブレット、PC）。
ホーム画面に追加すると、アプリのアイコン（`icon-*.png`）で起動できます。

## プライバシー

- 写真の読み込み・編集・書き出しはすべて端末内で行います
- ページの Content Security Policy で外部への通信を禁止しています（`connect-src 'none'` など）
- 設定は `localStorage`、「前回の続きから」のための写真と編集内容は IndexedDB に、どちらも端末内だけに保存します
- タイトル画面の「最初から」を選ぶと、保存した内容は削除されます（確認あり）

詳しくは [privacy.html](privacy.html) を見てください。

## 公開（GitHub Pages）

リポジトリの Settings → Pages で、公開するブランチとフォルダ `/ (root)` を選ぶと、
`https://<ユーザー名>.github.io/collage-generator/` で使えるようになります。
