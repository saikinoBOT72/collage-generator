プライバシーポリシー

フォトコラージュ（2L判 コラージュ作成ツール）／ 制定日: 2026年10月8日

要点
  • 選んだ写真は、あなたの端末のブラウザの中だけで処理されます。
  • 写真や作成した画像を、運営者や第三者のサーバーへ送信することはありません。
  • アクセス解析、広告、トラッキング用の Cookie は使っていません。

1. 取り扱う情報

本ツールが扱うのは、あなたが選択した写真ファイルと、レイアウトや枠などの設定だけです。氏名、メールアドレス、位置情報などの個人情報を入力・収集する機能はありません。

2. 写真の取り扱い

  • 写真の読み込み、縮小表示、切り抜き・拡大・回転、画像の書き出しは、すべてブラウザ内の処理（JavaScript と Canvas）で完結します。
  • 写真のデータは端末のメモリ上に一時的に置かれるだけで、ページを閉じたり再読み込みしたりすると消えます。端末のストレージにも保存しません。
  • 写真に含まれる撮影日時や位置情報などのメタデータ（Exif）を読み取って外部へ送ることはありません。書き出した画像にこれらのメタデータは引き継がれません。

3. 通信を行わない仕組み

本ツールのページには、外部との通信を禁止するセキュリティ設定（Content Security Policy: connect-src 'none' など）を入れています。そのため、仮にプログラムが通信しようとしても、ブラウザがそれをブロックします。外部のフォント、スクリプト、画像なども読み込んでいません。

4. 端末に保存する情報

次回も同じ設定で使えるよう、用紙サイズ・向き・分割・枠・書き出し形式の設定だけをブラウザの localStorage に保存します。写真は保存しません。この情報は端末の外へ送られず、ブラウザのサイトデータを消去すると削除されます。

5. 共有・保存について

書き出した画像の「ダウンロード」「共有・保存」は、端末の保存機能や OS の共有メニューを呼び出すだけです。共有先のアプリやサービスでの取り扱いは、それぞれの提供元のポリシーに従います。

6. ホスティング事業者のアクセスログ

本ツールをウェブ上で公開している場合、ページの配信元（ホスティング事業者）が、一般的なウェブサイトと同様に IP アドレスやブラウザの種類などのアクセスログを記録することがあります。これは HTML ファイルを配信する際のもので、写真の内容は含まれません。ログの取り扱いは各事業者のポリシーに従います。HTML ファイルを端末に保存して開いた場合は、この配信も発生しません。

7. 免責事項

  • 本ツールは現状のまま提供します。印刷の仕上がり（色味、トリミング位置、サイズの誤差など）は、プリンターや写真店の設定によって変わることがあります。
  • 本ツールの利用によって生じた損害について、運営者は責任を負いかねます。

8. ポリシーの変更

内容を変更する場合は、このページを更新し、上部の日付を改めます。

9. お問い合わせ

本ポリシーに関するお問い合わせは、本ツールの GitHub リポジトリ（saikinobot72/collage-generator）の Issue からお寄せください。
